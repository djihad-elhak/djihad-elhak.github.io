Architecture

Tabibi (طبيبي, "my doctor") is an appointment product for Algeria with three roles: patients find a doctor near them and book a visit on site or by video, doctors publish their available slots for a day and receive bookings, and an administrator approves new doctors. I built the backend API.

  • Search: doctors within a radius of the patient, by Haversine distance, filtered by specialty, insurance coverage and a day with free slots.
  • Slots: a doctor's day is a string of bits, one per hourly slot; booking a slot clears its bit, and a remote visit opens a Whereby room and mails the link.
  • Identity: names, birth date and card number are parsed from the OCR text of the Algerian national ID card.
  • Ratings: accepted only for a visit that has already happened.
  • Delivery: a Docker image built and pushed by GitHub Actions on every push to main.

What I would change

Writing the README later meant reading the code as a reviewer would, and I documented what I would change before any new deployment: move every secret out of the settings and rotate it, give the JWT a random subject and an expiry instead of carrying the password hash, hash administrator passwords, close three unauthenticated reads, and turn off debug mode. The list is public in the repository, next to the known functional gaps.
