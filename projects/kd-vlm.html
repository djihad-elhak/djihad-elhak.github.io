Feature distillation of a mobile vision-language model

Distilling MobileVLM V2 7B into its 3B sibling: the student keeps 96.8% of the teacher's accuracy with 2.3 times fewer parameters, and its visual representations move from 0.48 to 0.92 CKA with the teacher.

Context
Team project, 4 people
Period
2026
My part
Feature distillation, training and analysis
Stack
PyTorch, Hugging Face, LoRA, GQA, Kaggle 2× T4

01

Method

In a team project on knowledge distillation for mobile vision-language models, we compressed MobileVLM V2 7B into its 3B sibling. My part was feature distillation: the student learns to answer GQA questions and to reproduce the teacher's hidden states, both at the answer position and on the visual tokens.

  • GQA sample built image-disjoint with seed 42: 20,000 training images, 1,000 for development, 398 for testdev.
  • Teacher states are computed once and cached, so the 7B model never sits in memory during student training.
  • Training ran past Kaggle's 12-hour limit, so it is checkpointed and resumed in a second notebook that also evaluates and exports the merged model.

02

Results

GQA dev, 13,174 questions
ModelAccuracy
Teacher, 7B71.67%
Student 3B, zero-shot69.33%
Student 3B, feature distillation69.41%

The student keeps 96.8% of the teacher's accuracy with 2.3 times fewer parameters, 2.5 times fewer FLOPs and about 1.9 times lower latency.

CKA similarity with the teacher, before → after distillation

Visual tokens, before0.48
Visual tokens, after0.92
Answer position, before0.74
Answer position, after0.82

Feature distillation clearly aligned the representations. It did not significantly change accuracy, and I report that as it is.

  • Accuracy change against the zero-shot student: +0.08 points, 95% CI [−0.50, +0.72] by paired bootstrap.
  • Calibration got slightly worse: expected calibration error 0.034 → 0.042.
  • The cross-entropy-only control has not been run yet, so the effect of the teacher signal itself is not isolated.
  • The analysis also covers accuracy by question type, answer type and frequency, teacher–student agreement, accuracy-coverage, efficiency and qualitative disagreements.
