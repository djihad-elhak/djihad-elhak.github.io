# djihad-elhak.github.io

Source of my portfolio: **https://djihad-elhak.github.io**

A single static page: `index.html`, `style.css`, and `track.js` for the hero. The hero shows a simulated detection-and-tracking overlay (boxes, track ids, trajectories), the kind of view my medical imaging pipeline draws on microscope video. It runs on a canvas, pauses when off screen, and draws one still frame when the visitor prefers reduced motion.

Fonts are self-hosted: Chakra Petch and Instrument Sans, under the SIL Open Font License (texts in `fonts/`).
