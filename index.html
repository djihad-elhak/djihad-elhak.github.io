Selected work

On-premise GenAI platform for flight software

2026, personal research project

A platform an embedded software team can run on its own GPUs, built and measured on NASA's F´ flight framework: a knowledge graph of the code and its 560 requirements served over MCP, a LangGraph agent that writes requirement-tagged unit tests and proves them with the real build, the tests and mutation testing, a GPU sizing model calibrated on measured runs, and a web console engineers can use on site. Written up as a 6-page IEEE-style paper.

  • 21 of 28 traceability gaps closed with verified tests
  • 0.609 MAP for requirement-to-test retrieval
  • ±11% sizing error on decode throughput

Python, LangGraph, MCP, llama.cpp, vLLM, hybrid retrieval, Docker, GitHub Actions, Kaggle 2× T4

Live demo Code Paper

Feature distillation of a mobile vision-language model

2026, team of 4, my part: feature distillation

Compressing MobileVLM V2 7B into its 3B sibling for phones. The student, adapted with LoRA, learns to answer GQA questions and to reproduce the teacher's hidden states on the answer and on the visual tokens. Evaluated with bootstrap tests, calibration and CKA, including where it did not help.

  • 96.8% of the teacher's accuracy with 2.3× fewer parameters
  • 0.92 CKA alignment with the teacher on visual tokens, up from 0.48

PyTorch, Hugging Face, LoRA, GQA, Kaggle 2× T4
